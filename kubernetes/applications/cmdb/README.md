# cmdb

Telecom CMDB proof of concept with **synthetic data only**. Source, build and
workflow: [carnufex/cmdb](https://github.com/carnufex/cmdb) (`docs/drift.md`).

Public at <https://cmdb.rosenvall.se>, sign-in via Authentik (blueprint
`apps-cmdb.yaml` in `infrastructure/controllers/authentik-runtime/`, public client
`cmdb-web`, groups `cmdb-full`, `cmdb-region-nord`, `cmdb-projekt-a`).

## Components

| Resource | What |
|---|---|
| `cmdb-postgresql` | CNPG cluster, PostGIS image, 1 instance, `longhorn` 10Gi + 4Gi WAL. `postgis`/`pg_trgm` created in `postInitApplicationSQL` (postgis needs superuser). |
| `cmdb-api` | .NET 10 API. Init container `migrate` runs `--migrate` (EF migrations + type catalog sync) before the API starts. Probes `/health`, `/health/ready`. |
| `cmdb-web` | Angular SPA on nginx-unprivileged; proxies `/api/` to `cmdb-api:8080`, serves runtime `/config.json`. |
| `httproute.yaml` | `cmdb.rosenvall.se` on `gateway/external`. |

## Images and deploy

Images: `registry.rosenvall.se/carnufex/cmdb-{api,web}:sha-<git-short>@sha256:<digest>`.
They are built and pushed from a clean `main` in the cmdb repo with
`scripts/deploy.sh --deploy`, which also rewrites the image refs in `app.yaml`
and pushes this repo. ArgoCD auto-syncs.

## Secrets (Bitwarden, project homelab)

| Entry | Used by |
|---|---|
| `CMDB_DB_PASSWORD` | `cmdb-postgresql-bootstrap` (CNPG owner) and `cmdb-secrets` (`ConnectionStrings__Cmdb`) |
| `REGISTRY_PASSWORD`, `GHCR_PAT` | `cmdb-registry` pull secret |
| `CMDB_DEMO_PASSWORD` | Authentik demo users (not in this namespace) |

## Data

The database is not backed up: all data is synthetic and regenerated by the
cmdb datagen. Load or reload the full-scale network from a workstation:

```bash
kubectl -n cmdb port-forward svc/cmdb-postgresql-rw 25432:5432
# in the cmdb repo:
ConnectionStrings__Cmdb="Host=127.0.0.1;Port=25432;Database=cmdb;Username=cmdb;Password=<CMDB_DB_PASSWORD>" \
  dotnet run --project src/datagen -c Release -- --scale full --seed 1 --reset
```
