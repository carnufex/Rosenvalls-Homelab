# Rosenvalls-Homelab Agent Guide

## Source Of Truth

- The live cluster syncs from `https://github.com/carnufex/Rosenvalls-Homelab.git`.
- Kubernetes manifests live under `kubernetes/`, not `k8s/`.
- Local edits do not change the cluster until they are pushed to `origin`.
- `bootstrap.ps1` performs the imperative bridge from fresh cluster to GitOps.

## Architecture

- `tofu/` provisions Proxmox VMs and Talos configuration.
- `tofu/output/kubeconfig` and `tofu/output/talosconfig` are the local access artifacts.
- ArgoCD bootstraps from `kubernetes/bootstrap.yaml`.
- `kubernetes/infrastructure/` is the platform layer.
- `kubernetes/applications/` is the application layer and is generated by an ArgoCD `ApplicationSet`.
- Cilium Gateway API provides two entry points:
  - `gateway/external` for public traffic routed through Cloudflare Tunnel
  - `gateway/internal` for internal-only services

## Critical Bootstrap Secret

`bitwarden-access-token` in namespace `external-secrets` is intentionally manual and outside Git.

If this secret is missing, expect all of these to fail:

- `ClusterSecretStore/bitwarden-secretsmanager`
- `ExternalSecret` reconciliation across namespaces
- `cloudflared` startup
- cert-manager DNS validation for wildcard certificates
- app runtime secrets for ArgoCD, Authentik, and backup jobs

Always restore that secret before chasing downstream symptoms.

## Recommended Troubleshooting Order

1. Export `KUBECONFIG` from `tofu/output/kubeconfig`.
2. Check `kubectl get nodes`.
3. Check `kubectl get applications.argoproj.io -n argocd`.
4. Check `kubectl get clustersecretstore bitwarden-secretsmanager`.
5. Check `kubectl get externalsecret -A`.
6. Check `kubectl get pods -n cloudflare`.
7. Check `kubectl get certificate -n gateway cert-wildcard`.
8. Check `kubectl get gateway -n gateway external -o yaml`.
9. Check `kubectl get httproute -A`.
10. Treat Longhorn or PVC repair only after the secret and routing chain is green.

## Routing Conventions

- Canonical ArgoCD URL: `https://argo.rosenvall.se`
- Legacy ArgoCD alias: `https://argocd.rosenvall.se`
- Authentik route is attached to both internal and external gateways so OIDC can work for public apps.
- Monitoring routes should stay on the internal gateway unless there is an explicit reason to publish them.

## App Onboarding Rules

- Prefer GitOps-first changes in this repo.
- Keep bootstrap-only and break-glass secrets out of Git.
- New app folders under `kubernetes/applications/<name>/` automatically become ArgoCD apps.
- Do not add public `HTTPRoute` resources for a new app until the image, secrets, and health checks are known-good.
- New namespaces must be whitelisted in THREE places: `kubernetes/applications/project.yaml`
  (AppProject destinations), the ClusterSecretStore conditions
  (`infrastructure/controllers/external-secrets/cluster-secret-store.yaml`), and — if the app
  needs a LAN LoadBalancer IP — the Cilium selectors in
  `infrastructure/network/cilium/{ip-pool,announce}.yaml`.

## Container Images (GitHub Actions is billing-blocked — do not rely on it)

- GitHub Actions has been billing-blocked account-wide since July 2026: workflow jobs never
  start (not even self-hosted runners). Never push-and-wait-for-CI; never add workflows.
- All homelab images are published to the self-hosted registry **`registry.rosenvall.se`**
  (CNCF Distribution in-cluster, Cilium LB `192.168.1.225`, LAN-only grey-cloud DNS,
  Let's Encrypt cert, htpasswd user `homelab`, password in Bitwarden `registry-password`).
  Full runbook: `kubernetes/applications/registry/README.md`.
- Publish flow: local `docker build` → `docker push registry.rosenvall.se/carnufex/<app>` →
  bump tag/digest here (pinned apps) or `kubectl rollout restart` (`:latest` apps).
- Mirroring images: `crane copy` only (digest-preserving); every digest-pinned artifact must
  carry a `pinned-<first8>` tag or the weekly GC (`--delete-untagged`) will collect it.
- `ghcr.io/carnufex/*` is read-only legacy: old images remain there as rollback and every
  app's pull secret is dual-auth (ghcr.io + registry.rosenvall.se). Publish nothing new to GHCR.
